## Запуск

1. Создать .env файл
```env
openai_token="<mws токен>"
openai_endpoint="https://api.gpt.mws.ru/v1"
weaviate_host="weaviate"
weaviate_http_port=8080
embedding_model="bge-m3"
chat_model="llama-3.1-8b-instruct"
db_string="postgresql+asyncpg://mts:8f880hWV2525VLX@db:5432/truehack"
INFERENCE_API_ENDPOINT="http://embedding:3001"
```

2. Запустить docker compose:
```bash
docker compose up -d
```

Интерфейс пользовательского приложения: http://localhost:8081 \
Swagger документация api:  http://localhost:8081/docs


## Сервисы
### 1. embedding
```
host: embedding
listen-port: 3001
```
API для обработки загружаемых в weaviate файлов с помошью модели эмбеддинга

### 2. api
```
host: api
listen-port: 3000

exposed-port: 8081 -> 3000
```
Основное API ассистента

### 3. db
```
host: db
listen-port: 5432
```
PostgreSQL для хранения информации о клиентах.


### 4. weaviate
```
host: weaviate
listen-port: 8080, 50051
```
Векторная БД для индексации информации из базы знаний
